# ru-mood-classifier

Классификатор настроения русского текста: позитивный / негативный / нейтральный.

Синтетический датасет, честная валидация и сравнение нейросети с классическим правиловым ИИ.

## Запуск

```bash
pip install -r requirements.txt
python generator.py       # создаёт dataset.csv
python train.py           # обучает нейросеть
python test.py            # проверка
python ai_not_neural.py   # классический ИИ
```

## Структура

```
generator.py          генератор датасета из слотов
train.py              обучение нейросети (TF-IDF + MLP)
test.py               чат / файл / одна фраза
ai_not_neural.py      правиловый ИИ без нейросетей
```

## Как работает нейросеть

- Векторизация: word TF-IDF (1-2) + char_wb TF-IDF (3-5)
- Архитектура: MLP 80K -> 512 -> 128 -> 3, с BatchNorm и Dropout
- Сплит: GroupShuffleSplit по колонке `base` - варианты одного смысла не попадают в train и val одновременно
- Дисбаланс: взвешенный CrossEntropy + label smoothing
- Отбор лучшей эпохи по macro-F1, early stopping

Символьные n-граммы решают флективность русского: "сломалось" и "сломал" дают совпадающие фичи, хотя word-токенизатор их не связывает. Это подняло качество с 58% до 74%.

## Как работает классический ИИ

Строит словари частотности слов по каждому классу из датасета. Классифицирует входной текст суммированием весов. Есть базовая обработка отрицания - "не" инвертирует тональность следующего слова.

Плюс - полная прозрачность, показывает логику каждого решения. Минус - не видит связи между словоформами и не умеет в сложные контексты.

## Нейросеть vs Классический ИИ

- Нейросеть обучает веса на всём датасете, классический ИИ просто считает частоты
- char_wb n-граммы связывают словоформы - у правилового ИИ этого нет
- Нейросеть учится обрабатывать отрицания из контекста, правиловый ИИ инвертирует только одно следующее слово
- На смешанных фразах нейросеть комбинирует фичи, правиловый просто складывает баллы
- Классический ИИ полностью объясним (видно лог каждого решения), нейросеть - чёрный ящик
- Зависимости: нейросеть - PyTorch + sklearn, классический - только stdlib

## Что решено

- Утечка данных - GroupShuffleSplit по `base`. Раньше было 99% на валидации при 62% реальных, потому что варианты одной фразы попадали в обе выборки
- Флективность - char_wb n-граммы, без стоп-слов ("не", "ни", "без" - тональные сигналы)
- Дисбаланс - взвешенный loss + отбор по macro-F1
- Переобучение - dropout, label smoothing, grad clip, early stopping
- Память - разреженные матрицы, разворачиваются только по батчу (вместо 7 ГБ целиком)
